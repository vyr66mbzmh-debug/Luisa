The v0.70 import tooling (private, outside Git) adds these rules, recorded so later imports stay consistent:

- **Mid-page scheme starts.** When a scheme question starts part-way down a page, the start is given as a page and a y position, and the cut moves up to sit above that question's own "Question | Scheme | Marks | AOs" header row. Only that boundary page is shared between the two questions, and each crop holds only its own question's material.
- **Blank pages.** Blank scheme pages (2018 9MA0/02 pages 10, 22 and 32; 2018 9MA0/03 page 12) are attached to no question and are recorded in the evidence.
- **Page clamp.** Crops are clamped to the page edges.
- **Table rules.** Thin and thick (up to 2.5 pt) full-width table rules count as break rules. Label-column segments aligned with a full-width rule, and short thick vertical border segments, no longer block a break.
- **Figure clipping.** A figure box may be marked `clip` to crop inside a page frame, or inside a path whose box overstates its extent: 2019 9MA0/31 Q2 excludes the grey frame bar, and 2018 9MA0/02 Q13 trims an overstated normal-line path. A figure box that would cut through a drawing item is widened to include it, and each widening is logged.
- **Instructions per question.** Paper instructions may differ by question: in a combined paper, the Mechanics questions carry the Section B instruction about g verbatim and the Statistics questions do not.
- **Outlined text.** Question papers with outlined text (2019 9MA0/31 and 9MA0/32) are transcribed from page images, with figure bounds taken from the drawing paths.

The v0.71 import tooling adds:

- **Curve bounds.** A drawing's reported box includes its Bézier control points, which can sit well outside the drawn curve (October 2021 9MA0/32 Q4's trajectory reports a box reaching above the page header). When such a box straddles a figure box, the check now uses the curve's drawn extent, sampled along each Bézier segment. Every figure box that already passed gives an identical crop.
- **Figures on continuation pages.** A figure printed on a question's continuation page (October 2021 9MA0/31 Q2 scatter diagram) is cropped from that page and placed after the sentence that refers to it.
- **Header rows at page feet.** When a scheme question starts on a new page but its "Question | Scheme | Marks | AOs" header row sits at the foot of the previous page, that page is treated as a mid-page start so the header row goes with its own question. October 2020 9MA0/02 Q3, Q6, Q7 and Q8 use this rule. A scan of every imported paper found one earlier case, June 2019 9MA0/01 Q4, whose header row had printed as an empty table at the end of Q3's scheme. It is corrected in v0.71; no other crop changed.
