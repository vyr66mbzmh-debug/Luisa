Offline downloads

Choose chapters to keep on this device. Download inside the installed Luisa app, while connected, before travelling or teaching offline.

Install Luisa on your device

iPad or iPhone: open Luisa in Safari, use Share → Add to Home Screen, then open Luisa from its new icon. Download your chapters there. Safari and the installed app can have separate storage.

Mac: in Safari use File → Add to Dock where available. In Chrome use its install option. Windows: use Install app in Edge or Chrome. Android: use Chrome’s Install app or Add to Home screen option.

iiyama smartboard: installation depends on the board’s operating system and browser. Use the Windows or Android method only if offered. The actual board configuration has not yet been verified.

To check offline use: finish the download, turn off Wi-Fi and mobile data, fully close Luisa and reopen it from its icon. Open the chapter, reveal answers and open both PDFs. “Ready offline” confirms the stored files; this device test confirms they work on your device.

Preparing downloads…

Keep Luisa open until downloading finishes. Updates download a complete replacement for all saved chapters before switching. A failed or interrupted download leaves the previous copy usable. Your browser may remove saved data when space is low; check readiness before going offline.

Repair downloads while online if this page stops loading or saved files go missing.
